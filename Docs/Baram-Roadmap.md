# Baram — 원본 데이터 기반 MSW 전체 로드맵

> 마지막 갱신: 2026-09-14
> 현재 마일스톤의 실제 작업 상태는 Baram-M1-GDD.md 및 Phase 문서를 따른다.

## 비전과 출시 기준

원본 클라이언트 리소스와 제공된 게임 DB·스크립트를 기반으로, baram.in의 클래식 정보를 대조하여 탐험·대화·사냥·거래·성장이 이어지는 MSW 바람 게임을 만든다.

출시 기준: 지역 간 왕복과 게임 진행이 정상 작동하고, 플레이어별 이동·외형·전투·보상이 동기화되며, 서버가 아이템·금전·보상을 검증하고, 재접속 시 진행이 복구되어야 한다. 데이터 출처와 원본 대비 변경 사항을 추적할 수 있어야 한다.

## 전체 적용의 8단계

1. 원본 데이터와 사이트 근거 정리, 원본 ID와 MSW ID 대응.
2. 캐릭터별 상태·이동·충돌·동기화 기반.
3. 맵·오브젝트·출입구·음악 및 환경 상호작용.
4. NPC·대화·선택지·서비스 연결.
5. 아이템·가방·장비·상점 거래.
6. 몬스터·공격·피격·마법·보상.
7. 레벨·직업·퀘스트와 성장 흐름.
8. 통합 저장·재접속·다인 플레이·전체 회귀 검증.

M1은 각 단계의 최소 기능으로 한 생활권을 완성한다. 전체 데이터 일괄 이식 완료를 의미하지 않는다. 이후 마일스톤은 검증된 데이터 변환·상호작용 구조에 콘텐츠를 추가한다.

## 이후 작업

- 닉네임: 사용자가 보류를 해제하면 배정.
- 원본 로딩 연출·타이틀의 나머지 기능 복원: 전용 리소스와 동작 근거 확인 후 배정. 현재 로딩 텍스트 화면을 원본 연출 완료로 취급하지 않는다.
- 성별별 허용 헤어 목록·염색·장비 레이어 전체 매핑: M2.
- 창고·금전 보관·그룹·유저 교환: M4.
- 이벤트·캐시·레이드 등 제공 DB의 커스텀 콘텐츠: 클래식 목표와 구분하여 검토 후 배정. 자동 이식하지 않는다.
- 모바일 조작 최적화: PC 기본 조작 검증 이후 범위 결정.

## 출처 사용 원칙

로컬 파일은 리소스·ID·데이터·동작의 1차 구현 근거이고, baram.in은 클래식 지도 연결·아이템·스킬·조작의 비교 근거다. 충돌하면 원본 값과 사이트 값을 함께 기록하고 적용값을 따로 결정한다. 사이트에서 찾지 못한 값을 추정으로 채우고 원본이라고 부르지 않는다.
