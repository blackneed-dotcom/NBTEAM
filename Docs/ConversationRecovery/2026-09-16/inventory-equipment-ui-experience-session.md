## 사용자 요청 흐름과 결과

### 1. 대화 복구 및 인벤토리 입력

사용자는 이전 대화와 보관된 채팅을 가져올 수 있는지 물었고 관련 대화 전체를 맥락으로 제공했다.

주요 요청:
- “인벤토리 좌클릭 우클릭 버그 수정해”
- “인벤토리창 아이템을 좌클릭 더블클릭하거나 우클릭해도 반응이 없어 수정해줘”
- 오른쪽 마우스로 정보를 연 뒤 다시 클릭하면 파란 정보창이 닫히도록 요청.
- item2_db 장비의 실제 착용 이미지 및 타입·이미지·착용·염색·최대 이후 필드 연결 요청.

구현:
- UI 부모 배율을 고려한 클릭 좌표 계산.
- 좌클릭 더블클릭 장착/사용, 우클릭 정보 열기/닫기.
- 중복 입력 방지 및 페이지/아이템 변경 시 입력 상태 정리.
- item2_db 154개 레코드의 조건·공격력·거래·수리·명명 등 연결.
- 실제 원본 이미지가 있는 152개 장비, 118개 착용/염색 조합 연결.
- ‘죽었을’ 동작, 수련봉/수련검 착용 이미지는 명시적으로 제외.

### 2. 장착 표시·내구도·모션

사용자:
“아이템들을 장착했을 때 인벤토리창에 없어져야해 그리고 벗으면 다시 생기게 하고 현재는 내구도 안닳게 만들어주고 현재 무기 장착했을 때 모션들 무기에 맞춰서 다 설정해줘”

첫 구현:
- 장착 슬롯을 인벤토리 표시 목록에서 제외.
- DurabilityLossEnabled=false로 공격 및 내구형 사용 아이템의 마모 중지.
- 원본 winbaram.exe의 무기 분류 및 프레임 표에 따라 검/창 모션 연결.
- 몸·머리·무기 프레임 동기화와 상태창 미리보기 보완.
- 누락된 머리 프레임166개를 원본 이미지83개로 연결.
- 투척·피격 등 무기를 표시하지 않는 원본 동작 반영.
- Shift+T → W: 무기 해제.

검증:
- 원본 매핑3040개 정적 검사.
- 실제 렌더러에서 네 방향 공격32개 및 기타 동작/대기 복귀 확인.
- 실제 공격4회에서 내구도 유지.
- 빌드 오류0개.

## 경험치 변경 논의 — 미적용

사용자 최초 요청:
“현재 레벨업에 필요한 경험치를 레벨5부터 99까지있는 데이터들을 10배 상승시켜줘”

정정:
“6~99로 수정해줘”

이어 질문:
“누적 경험치로 안하면 생기는 문제 알려줘”

확인한 현재 구조:
- 원본 표: level_db.txt
- 게임 적용: RootDesk/MyDesk/BaramStats/BaramLevelData.mlua
- SourceExperience는 누적 기준, 직업0~4,최대99레벨.
- 0~5레벨은 직업0 표 공통 사용.
- ResolveLevel은 총 경험치와 다음 레벨 누적 기준을 비교한다.
- GainMessage는 인접 레벨 누적 기준의 차이를 분모로 획득 비율을 계산한다.
- BaramWorld는 획득 경험치를 state.exp에 더한다.
- 기존 레벨을 강제로 낮추는 로직은 없다.
- 경험치에 금화의32비트 상한을 적용하는 코드는 확인되지 않았다.

사용자에게 설명한 내용:
- 비누적 방식 자체에 문제는 없다.
- 다만 현재 코드에서 표만 비누적값으로 바꾸면 레벨 판정과 퍼센트가 어긋난다.
- 비누적 전환에는 레벨업 때 필요 경험치 차감, 초과분 이월, 여러 레벨 상승, 기존 저장 변환, 퍼센트 수정이 필요하다.
- 누적 기준값 자체10배와 구간 필요량10배는 경계에서 다르다.

평민 예:
- 5레벨 누적1,200.
- 6레벨 누적2,160.
- 5→6 추가 필요960.
- 추가 필요량10배는9,600.
- 따라서 5레벨 기준 유지 시 6레벨 누적은10,800.
- 누적2,160 자체를10배하여21,600으로 바꾸면 추가 필요량은20,400이다.

마지막 제안:
“6~99레벨에 도달하는 사냥량10배”가 의도라면, 누적 저장 방식은 유지하면서 각 목표 레벨6~99의 구간 차이를10배하고 재합산하는 방식이 맞다고 설명했다.

중요:
- 위 설명 이후 사용자는 “알겠어 지금까지의 대화 내용을 저장해줘”라고 요청했다.
- 경험치 파일은 아직 수정하지 않았다.
- 비누적 방식으로 전환하라는 승인은 없었다.
- 현재 요청은 이 대화 기록 저장이며, 경험치 변경 완료로 보고하면 안 된다.
- 후속 경험치 작업은6~99 범위를 유지하고 누적값 배율/구간 배율의 차이를 반영해야 한다.
