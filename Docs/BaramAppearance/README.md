# 원본 외형 조합

원본 BODY.EPF/Head.EPF의 프레임과 BODY.PAL/Head.PAL을 직접 읽어 몸·머리를 별도 레이어로 등록한다. 원본 자료는 변경하지 않는다.

- 기본 몸: 남자 시작 프레임 0, 여자 104. 각각 처음 12프레임을 사용한다.
- 머리: 처음 10종, 시작 프레임 `머리 번호 × 100`. 각각 처음 12프레임을 사용한다.
- 방향: 뒤 0, 오른쪽 3, 앞 6, 왼쪽 9. 각 방향 3프레임.
- 팔레트: DLPalette 헤더의 애니메이션 색상 개수를 반영하여 `block + 32 + count × 2`부터 RGB를 읽는다. 인덱스 0은 투명.
- 원본 프레임의 left/top을 유지하고 48×72 캔버스의 (24,60)에 발 원점을 맞춘다. 게임 렌더러 위치는 (0,0.24,0).
- 144개 레이어 중 동일 픽셀을 공유하는 리소스를 제외하면 84개. assets.json의 canonical과 ruids.json으로 추적한다.

BaramAppearance의 단일 목록을 생성 UI와 BaramMinimalController가 함께 사용한다. 좌우는 머리, 남녀 버튼은 몸, 회전은 방향을 바꾼다. 기존의 단일 합성 캐릭터 대신 몸 위에 머리 레이어를 렌더링한다.

저장 키 BaramCharacterV1은 유지한다. 새 값은 `2:gender:nation:totem:hair`이다. 이전 `gender:nation:totem`도 읽으며 머리는 0으로 시작한다. 기존 캐릭터 수정 시 서버에서 국가와 수호신을 유지한다. 취소하면 저장된 선택으로 되돌린다.

프레임 분리와 시각 합성은 확인했지만 BODY.TBL/Head.TBL의 원본 선택 규칙은 해독되지 않았다. 현재 머리 10종은 두 성별에 모두 제공한다. 원본 생성 창의 성별 제한·목록 순서 전체를 그대로 복원했다는 의미는 아니다. 뒤쪽 몸 프레임까지 동일 간격이라고 가정하지 않는다.

분석 이미지: combinations.png. 추출: analyze.cjs/export.cjs. 업로드 목록을 확보한 후 integrate.cjs가 공유 스크립트와 UIBuilder 레시피를 생성한다.
