# 원본·현재 베이스·baram.in 비교

조사일: 2026-09-14. 이 디렉터리는 분석/변환 준비 산출물이며 게임 런타임 적용 완료를 뜻하지 않는다.

## 현재 베이스

Maker 실행 문맥에서 BaramMinimalTest, RectTile, 단일 로컬 BaramActor, entry=world, StorageKey=BaramCharacterV1을 읽기 전용으로 확인했다. 접속·외형·채팅·HUD를 재사용한다. 온라인 캐릭터별 상태·타일 충돌·NPC·전투는 해당 단계에서 연결한다.

## 확보한 자료

정규화된 정상 형식 행은 맵 6,447, NPC 332, NPC 배치 1,029, 몬스터 903, 몬스터 배치 12,355, 아이템 1,957개다. 스크립트 파일 454개와 CMAP 파일 628개를 조사했다. 맵 DB 레코드 수와 실제 맵 자산 수는 다르므로 전체 맵 자산을 확보했다고 간주하지 않는다.

클라이언트 DAT·EPF·PAL 및 CMAP 리소스 외에 게임 DB와 서버 동작용 텍스트 스크립트가 있다. C/C++ 클라이언트 전체 소스가 확인됐다는 의미는 아니다. 실행 파일을 실행하거나 원본 DB를 수정하지 않았다.

## 웹과의 대조

- [부여성 지도](https://baram.in/maps/AAAAAAAAAAAAAAAAAAAAAO8RrQUH4wmrigJIQ-XCrdA): 왕초보사냥터 입구 중심 (33.5,121), 주막 (36.5,104), 푸줏간 (38.5,128). 로컬 warp_db의 각각 두 진입 타일과 대조한다. 소수 좌표는 웹의 입구 중심 표시로 해석하며 MSW 월드 좌표로 그대로 사용하지 않는다.
- [주막연실이네](https://baram.in/maps/AAAAAAAAAAAAAAAAAAAAACedjVBA5M6lcdRdEXGpQwE): 부여성으로 나가는 두 출입구를 비교했다.
- [옥이네푸줏간](https://baram.in/maps/AAAAAAAAAAAAAAAAAAAAAIZ0QL2R5hq5_uAdP8iVMNg): 부여성 연결을 비교했다.
- [도토리](https://baram.in/items/%EB%8F%84%ED%86%A0%EB%A6%AC): 다람쥐·경험치 10·왕초보사냥터 연결이 로컬 자료와 일치한다.
- [토끼고기](https://baram.in/items/%ED%86%A0%EB%81%BC%EA%B3%A0%EA%B8%B0): 토끼·경험치 5·왕초보사냥터 연결이 로컬 자료와 일치한다.
- [목도](https://baram.in/items/%EB%AA%A9%EB%8F%84): 내구도 1000은 로컬과 일치한다. 사이트의 강화 안내를 기본 지급 규칙으로 해석하지 않는다.
- [단축키](https://baram.in/shortcuts): 아이템 사용·줍기·장비 조작의 비교 근거다. 현재 MSW 채팅 입력과 충돌 여부를 구현 시 검증한다.

왕초보사냥터 상세 페이지는 web 도구에서 cache miss로 열리지 않았다. 부여성의 실제 링크와 로컬 map/warp/spawn 데이터를 사용했고, 해당 상세 페이지 내용을 확인했다고 주장하지 않는다.

| 위치 | 발견 내용 | 처리 |

10개 예외 모두 M1의 선택 레코드 밖이다. 원문·줄 번호와 거부 기록은 inventory.json에 유지한다. 단순 공백 분리로 모든 테이블을 읽으면 한글 이름·툴팁이 깨지므로 표별 어댑터로 처리한다.

## 다음 해석 대상

- 드롭: npc/monster/부여고구려성/초보사냥터.txt 및 function/Monster_Functions.txt. 다람쥐의 100개 묶음 분기와 DROPITEM의 end 제어 흐름은 원본 스크립트 엔진 의미 확인 전까지 일반 확률 합산으로 바꾸지 않는다.
- mobspawn 간격 숫자 300/600의 단위를 별도로 확인한다. mob_db 이동 간격의 ms 주석을 다른 표에 적용하지 않는다.
- 서버 데이터에는 커스텀 상인·고급 콘텐츠가 섞여 있다. 기본 클래식 경로와 구분한다.
- script-symbols.json은 스크립트 정의의 후보 인덱스다. import 순서·조건부 실행·동일 이름 우선순위까지 검증한 인터프리터가 아니다.

## 산출물·재현

- audit.cjs: 읽기 전용 분석 프로그램. 실행 `node Docs/BaramSource/audit.cjs`.
- inventory.json: 파일 해시·정상 행 수·예외·맵 자산 검증.
- normalized-tables.json: UTF-8로 정규화된 원본 행, 파일·줄 번호 포함.
- m1-manifest.json: 첫 목표의 맵·NPC·몬스터·아이템·상점·출입구 자료.
- script-symbols.json: 스크립트 이름·파일·줄 번호 후보.

검증 결과: 프로그램의 핵심 행 assert 통과, M1 누락 맵 및 미해결 NPC 스크립트 0. 신규 게임 동작에 대한 play 검증은 아직 수행하지 않았다.
