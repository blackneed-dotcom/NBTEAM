# 바람 스크립트 -> mlua 변환기

원본 서버의 스크립트(`magic/`, `function/`, `script_essential.txt`,
`script_timer.txt`)를 읽어서 메이플월드 mlua 소스로 뽑아낸다.

## 왜 이렇게 하나

`spell_db.txt` 의 `cast` 칸은 스크립트 이름(`@백열장`)이다. 즉 **마법 = 스크립트**라,
스크립트를 돌릴 수 있으면 마법 385개가 한꺼번에 풀린다.

게임 안에 해석기를 넣는 대신 **여기서 미리 루아로 번역**한다. 메이플월드가
어차피 루아라서, 번역해두면 게임에선 그냥 함수 호출이다. 실행할 때마다
구문을 뒤질 필요가 없어서 빠르다.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `blex.py` | 토크나이저 |
| `bparse.py` | 파서 (AST) |
| `emit.py` | AST -> 루아 소스 |
| `build.py` | 고른 주문만 골라 뽑기 |
| `check.py` | 전부 파싱되는지 확인 |
| `links.py` | callfunc/goto 가 실제로 있는 곳을 가리키는지 확인 |
| `coverage.py` | spell_db 주문과 스크립트 짝 맞추기 |

## 쓰는 법

```
python3 check.py              # 전체 파싱 확인
python3 build.py @백열장        # 주문 하나와 거기서 부르는 함수까지 뽑기
```

## 원본 문법에서 조심할 것

* **0 이 거짓이다.** 루아는 0 도 참이라, 조건은 전부 `R.t()` 를 거친다.
* **비교식이 1/0 을 돌려준다.** `set @x, (a > b);` 같은 코드가 실제로 있다.
* **`/` 가 정수 나눗셈이다.**
* **`+` 가 한쪽이 글자면 이어붙이기다.**
* `end;` 는 스크립트 전체를 끝낸다(`return;` 은 그 함수만).
* `@변수` 는 callfunc 를 건너서도 살아있다 — 부른 쪽이 넣어둔 `@name$` 을
  불린 쪽이 읽는 코드가 실제로 있다.
* `callfunc "X"` 는 `FUNC_X` 블록을 부른다.

원본에 있는 문법 오류도 그대로 받아준다(인자 끝 쉼표, `if(A) || (B) {`,
주석 처리된 블록 머리, 갈 곳 없는 goto).
